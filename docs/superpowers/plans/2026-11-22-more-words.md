# More words — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add about 230 everyday words from the spec's list, with two new topics (Animals, Hobbies & sports). Every new word gets correct grammar options, sensible pattern kinds and a frequency rank.

**Architecture:**
- Data only, plus two new pattern kinds:
  - `data/words.js` gains the words and topics.
  - `data/patterns.js` gains the `wild` kind, added to the `var` and `this` slots, and the `hobby` kind, added to the `like` slot.
  - `data/ranks.js` is regenerated by `tools/rank-words.mjs`.
- Grammar comes from the existing word options: `soft`, `cmp`, `h`, `m`, `pe`, `pl`, `a`, `the`, `to`, `at`, `from`, `p`, `ing`, `gloss`, `note`, `ex`, `nc`.

**Tech Stack:** Plain ES modules, `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-22-more-words-design.md`

## Global Constraints

- **Saved ids never change.** A moved word keeps its old id through an explicit `id` option. `G()` spreads the options after building the id, so `{ id: 'nature:kedi' }` wins.
- **No duplicate Turkish spellings**, except an explicit allowlist in the test. The allowlist holds the existing duplicates plus `ay` (moon / month).
- **Words that fit no pattern** (`nc: 1`, or a kind no slot uses) must have an `ex` example or a `note`, so no card is empty.
- **Wild animals** (`kind: 'wild'`) appear only in "Is there ___?" and "This ___". Pets and farm animals stay `kind: 'animal'`.
- **Verbs** fit every verb pattern, so a verb that makes silly sentences ("Let's die") is `nc: 1` with an `ex`, or dropped.
- **Ranks** come only from `tools/rank-words.mjs` with `tr_50k.txt` (FrequencyWords 2018). New spellings that collide with a common word get a `DAMPEN` entry.
- **Release:** `sw.js` `CACHE = 'turkish-v10'`. The README says "about 940 words", or whatever the final count rounds to.
- **Tests** run with `"/c/Program Files/nodejs/node.exe" --test tests/` (baseline 123).
- **Sentence review:** a scratchpad script prints every generated sentence for the new words of a task (`fill` over every fitting template). Read all of them before each commit.

## Review Focus

1. **Progress on the moved animals.** A phone with `nature:kedi` learned or selected must still show it after the move. (Task 1 test: the ids stay the same.)
2. **Wrong or silly generated sentences**, such as "a rice", "I have a giraffe", "Let's be born", or a broken stem like "nehire" for "nehre". (Each task's sentence review, plus the grammar spot tests.)
3. **Duplicate spellings** that make search show two unrelated blocks. (Task 1 test, with an allowlist.)
4. **Empty word cards** for words that fit no pattern. (Task 2 test, run again as the suite grows.)
5. **Missing ranks.** New words must not be left unranked or at 0, which would mean the spelling isn't in the subtitle list. (Task 5 test, plus the tool's "Zero-scored" line.)
